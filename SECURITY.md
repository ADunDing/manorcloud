# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub:
**Security → Report a vulnerability** on this repository.
Don't open a public issue for them.

Include what you found, how to reproduce it, and the ManorCloud version
(`manorcloud --version`). You'll get a reply as soon as possible, and a fix will be
released before the details are made public.

## Supported versions

Only the latest release receives security fixes.
